## Controles de EA SPORTS UFC 5 no PS5: O Layout Completo de Botões do PS5

Se você está procurando os controles de EA SPORTS UFC 5 no PS5, entrar no Octógono pode parecer intimidante até que você saiba qual botão faz o quê no seu DualSense. A diferença entre acertar o golpe que encerra a luta e ser pego em uma finalização geralmente se resume a aprender o esquema de controles antes de o sino tocar. No PS5, EA SPORTS UFC 5 mapeia o movimento para o analógico esquerdo, o movimento de cabeça para o analógico direito, e usa os botões de ombro como modificadores para bloqueios, grappling e golpes, com os botões de ação controlando socos, chutes, joelhadas e cotoveladas.

EA SPORTS UFC 5 foi lançado em 27 de outubro de 2023 para PlayStation 5 e Xbox Series X/S. De acordo com sua [entrada do EA Sports UFC 5 na Wikipédia](https://en.wikipedia.org/wiki/EA_Sports_UFC_5), foi o primeiro jogo da série construído com a engine Frostbite, trazendo um sistema de dano reformulado e finalizações contínuas. O hub de controles oficiais da EA e a página da PlayStation Store retornaram erros de acesso durante a pesquisa, então os mapeamentos verificados do DualSense abaixo vêm de guias de controle de terceiros do [guia de controles de UFC 5 do Ginx.tv](https://www.ginx.tv/en/controls-2) e do [guia de controles de UFC 5 do RealSport101](https://realsport101.com/article/ufc-5-controls-guide).

## Escolhendo Seu Esquema de Controle e Estilo de Jogo em UFC 5

Antes de memorizar os comandos, escolha um estilo de jogo e um tipo de controle de grappling. O Ginx.tv observa que UFC 5 oferece quatro estilos de luta:

- **Competitivo:** O padrão equilibrado usado para modos competitivos online.
- **Simulação:** Dano real, resistência real e consequências em tempo real.
- **Nocaute:** Enfatiza o poder de nocaute reduzindo a recuperação de saúde.
- **Stand and Bang:** Apenas trocação, com grappling, quedas, clinch e finalizações desativados.

Se você fica frustrado com grappling, Nocaute ou Stand and Bang permitem que você dependa dos golpes. Para o próprio grappling, escolha **Legacy Grapple Controls** para profundidade máxima, **Grapple Assist** para um jogo de chão simplificado, ou **Hybrid** para misturá-los. As configurações de controle podem ser alteradas a qualquer momento, mas o Modo Carreira bloqueia o estilo de jogo escolhido quando você cria um save.

## Controles de Luta em Pé de EA SPORTS UFC 5 para PS5

O jogo em pé é onde a maioria das trocas começa. Os ataques básicos usam os botões de ação, enquanto L1, L2, R1 e R2 atuam como modificadores.

### Entradas Básicas de Luta em Pé

| Ação | Controle do PS5 |
| --- | --- |
| Locomoção / Movimento | Analógico esquerdo em qualquer direção |
| Soco Direito | Triângulo |
| Soco Esquerdo | Quadrado |
| Chute na Perna Direita | Círculo |
| Chute na Perna Esquerda | X |
| Movimento de Cabeça | Analógico direito em qualquer direção |
| Trocar de Base | R3 / Pressionar R3 |
| Provocações | D-pad em qualquer direção |
| Modificador Técnico | Segurar L1 |
| Modificador de Corpo | Segurar L2 |
| Modificador de Assinatura | Segurar R1 |
| Bloqueio Alto / Finta de Golpe | Segurar R2 |
| Bloqueio Baixo / Agarrada de Perna (com Tempo) | Segurar R2 + L2 |

### Golpes, Grappling e Movimento Avançado

- **Ganchos:** Pressionar L1 + Quadrado ou L1 + Triângulo
- **Uppercuts:** Pressionar R1 + Quadrado ou R1 + Triângulo
- **Overhands:** L1 + Segurar Quadrado ou L1 + Segurar Triângulo
- **Chutes no Corpo:** Pressionar L2 + X ou L2 + Círculo
- **Chutes na Cabeça:** Pressionar L1 + X ou L1 + Círculo
- **Queda de Perna Única de Wrestling:** Pressionar L2 + Quadrado + X
- **Queda de Duas Pernas de Wrestling:** Pressionar L2 + Triângulo + Círculo
- **Queda de Perna Única Potente:** L2 + Quadrado + Segurar X
- **Clinch de Coleira Simples:** Quadrado + X
- **Defender Queda:** Segurar L2 + R2
- **Defender Clinch:** Mover o analógico direito em qualquer direção
- **Investida Menor:** Mover rapidamente o analógico esquerdo
- **Investida Maior:** Segurar L1 + Mover o analógico esquerdo
- **Investida com Pivô:** Segurar L1 + Mover o analógico direito
- **Esquiva de Assinatura:** Segurar L1 + Mover rapidamente o analógico esquerdo

## Controles de Clinch: Como Agarrar e Bater no Clinch

Manter um oponente no clinch abre quedas, arremessos e golpes curtos. O layout do clinch reflete vários modificadores da luta em pé.

| Ação | Controle do PS5 |
| --- | --- |
| Rotacionar / Empurrar / Puxar Oponente | Mover o analógico esquerdo |
| Modificador de Transição Avançada | Segurar L1 |
| Modificador de Queda / Finalização | Segurar L2 |
| Modificador de Golpe | Segurar R1 |
| Bloqueio Alto | Segurar R2 |
| Bloqueio Baixo | Segurar R2 + L2 |
| Queda de Perna Única de Wrestling | Pressionar L2 + Quadrado + X |
| Queda de Duas Pernas de Wrestling | Pressionar L2 + Triângulo + Círculo |
| Modificador de Perna Única / Duas Pernas | Mover o analógico esquerdo para Direita, Cima ou Baixo |
| Defender Queda / Arremesso | Segurar L2 + R2 |
| Defender Finalização | Segurar R2 |
| Modificador de Defesa de Perna Única / Duas Pernas | Mover o analógico esquerdo para Esquerda, Cima ou Baixo |
| Escape do Clinch | Mover o analógico esquerdo para a Esquerda |

Os golpes no clinch usam estas entradas:

- **Ganchos:** Pressionar L1 + Quadrado ou L1 + Triângulo
- **Uppercuts:** Pressionar R1 + Quadrado ou R1 + Triângulo
- **Joelhadas no Corpo:** Pressionar L2 + X ou L2 + Círculo
- **Joelhadas na Cabeça:** Pressionar L1 + X ou L1 + Círculo
- **Cotoveladas:** Pressionar L1 + Quadrado + X ou L1 + Triângulo + Círculo

## Controles de Chão: Grapple Assist, Legado e Ground-and-Pound

Os controles de chão variam de acordo com o esquema. O Grapple Assist simplifica as transições para direções do analógico esquerdo, enquanto o Legado usa o analógico direito.

### Chão Geral e Grapple Assist

| Ação | Controle do PS5 |
| --- | --- |
| Alavanca de Grappling | Mover o analógico esquerdo |
| Grappling Avançado / Transição | Mover o analógico direito |
| Modificador de Transição Avançada de GnP | Segurar L1 |
| Modificador de Golpes no Corpo | Segurar L2 |
| Modificador de Ground and Pound | Segurar R1 |
| Bloqueio Alto | Segurar R2 |
| Bloqueio Baixo | Segurar R2 + L2 |
| Levantar (Assist) | Analógico esquerdo para Cima |
| Finalização (Assist) | Analógico esquerdo para a Esquerda |
| Ground and Pound (Assist) | Analógico esquerdo para a Direita |
| Defender Transição | Segurar R2 + Mover o analógico direito ou analógico esquerdo |

### Grappling Legado e Golpes de Ground-and-Pound

- **Transição (Legado):** Mover o analógico direito em qualquer direção
- **Finalização (Legado):** Segurar L2 + Mover o analógico direito em qualquer direção
- **Transições Adicionais (Legado):** Segurar L1 + Mover o analógico direito em qualquer direção
- **Ganchos (GnP):** Pressionar L1 + Quadrado ou L1 + Triângulo
- **Diretos no Corpo (GnP):** Pressionar L2 + Quadrado ou L2 + Triângulo
- **Ganchos no Corpo (GnP):** Pressionar L2 + L1 + Quadrado ou L2 + L1 + Triângulo
- **Cotoveladas (GnP):** Pressionar R2 + Quadrado ou R2 + Triângulo
- **Movimento de Cabeça (GnP):** Mover o analógico direito para a Esquerda ou Direita
- **Defesa de Postura (GnP):** Segurar L1 + Mover o analógico direito para a Esquerda ou Direita

Nem todos os lutadores compartilham o mesmo conjunto de golpes. Pause e verifique a lista de golpes do seu lutador no modo offline para confirmar quais ataques e finalizações ele pode executar.

## Perguntas Frequentes Sobre os Controles de EA SPORTS UFC 5 no PS5

### Quais são os controles básicos de EA SPORTS UFC 5 no PS5 que os jogadores devem aprender primeiro?

Comece com o movimento no analógico esquerdo e o movimento de cabeça no analógico direito. Depois, aprenda os botões de ação: Quadrado (soco esquerdo), Triângulo (soco direito), X (chute na perna esquerda) e Círculo (chute na perna direita). Depois disso, pratique segurar L1, L2, R1 e R2 para modificar golpes, bloqueios e grappling.

### UFC 5 tem uma opção de controle simplificada no PS5?

Sim. O Grapple Assist oferece entradas de chão simplificadas usando o analógico esquerdo: para Cima para levantar, para a Esquerda para finalização e para a Direita para ground and pound. O Hybrid mistura essas entradas com os controles Legado. Você pode alterar as configurações de controle a qualquer momento, mas os estilos de jogo do Modo Carreira são bloqueados quando o save é criado.

### Onde posso verificar os golpes específicos de um lutador em EA SPORTS UFC 5?

Pause a luta e abra a lista de golpes para confirmar quais golpes, quedas e finalizações seu lutador possui. Guias de terceiros do Ginx.tv e do RealSport101 também recomendam praticar nos tutoriais do Modo Carreira ou em lutas offline para construir memória muscular.

### Quando EA SPORTS UFC 5 foi lançado e ele usa uma nova engine?

Ele foi lançado em 27 de outubro de 2023 e foi o primeiro jogo da série desenvolvido com Frostbite em vez de Ignite, de acordo com sua entrada na Wikipédia. Essa mudança de engine suportou o novo sistema de dano e as finalizações contínuas referenciadas nos guias de controle.
